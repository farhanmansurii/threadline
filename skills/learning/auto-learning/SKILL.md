# RelayKit Auto-Learning

Auto-learning creates candidates, not authority.

Silent behavior:

- observe repeated patterns
- draft project-scoped instincts
- update confidence scores

Approval required:

- global promotion
- AGENTS/config edits
- skill/command creation
- Obsidian knowledge graph updates
- sensitive preference storage
