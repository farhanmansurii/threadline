# Learnings

Capture a durable project learning.

## Steps

1. Summarize the recurring pattern, correction, or preference.
2. Decide scope: project-local or globally reusable.
3. Ask for approval before storing anything.
4. Store only the compressed lesson — not full chat history.

## When to use

- After discovering a non-obvious project convention
- After a correction that should not repeat
- After identifying a recurring pattern worth encoding
