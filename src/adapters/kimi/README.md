# Kimi Adapter

Responsibilities:

- Install Threadline skills into `~/.kimi/skills`
- Install commands into `~/.kimi/commands`
- Manage `~/.kimi/config.toml` with a Threadline-managed block
- Generate one-time project/folder knowledge docs (planned)
- Write curated knowledge graph documents to Obsidian or local state (planned)
- Avoid treating generated docs as canonical until reviewed

Implemented in `adapter.mjs`.
